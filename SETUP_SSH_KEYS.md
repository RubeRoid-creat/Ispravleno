# Настройка SSH ключей для подключения к серверу

## Проблема

Сервер настроен на аутентификацию только по SSH ключам (не по паролю):
```
Permission denied (publickey)
```

## Решение: Настройка SSH ключей

### Шаг 1: Проверьте, есть ли у вас SSH ключи

```powershell
# Проверьте наличие ключей
ls ~/.ssh/
```

Если есть файлы `id_rsa` и `id_rsa.pub` (или `id_ed25519` и `id_ed25519.pub`) - переходите к шагу 3.

### Шаг 2: Создайте SSH ключ (если его нет)

```powershell
# Создайте новый SSH ключ
ssh-keygen -t ed25519 -C "your_email@example.com"

# Или используйте RSA (если ed25519 не поддерживается)
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

**При запросе:**
- **Файл для сохранения:** Нажмите Enter (используется по умолчанию)
- **Парольная фраза:** Можете оставить пустым или ввести пароль

### Шаг 3: Скопируйте публичный ключ на сервер

**Вариант A: Через ssh-copy-id (если доступен)**

```powershell
ssh-copy-id root@212.74.227.208
```

**Вариант B: Вручную (если ssh-copy-id не работает)**

1. **Покажите ваш публичный ключ:**
```powershell
cat ~/.ssh/id_ed25519.pub
# или
cat ~/.ssh/id_rsa.pub
```

2. **Скопируйте весь вывод** (начинается с `ssh-ed25519` или `ssh-rsa`)

3. **Обратитесь к администратору сервера** и попросите добавить этот ключ в файл:
   ```
   /root/.ssh/authorized_keys
   ```

   Или если у вас есть другой способ доступа к серверу, выполните:
   ```bash
   # На сервере
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   echo "ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ" >> ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
   ```

### Шаг 4: Проверьте подключение

```powershell
ssh root@212.74.227.208
```

Если подключение успешно - переходите к загрузке APK.

## Альтернатива: Загрузка через веб-интерфейс

Если настройка SSH ключей невозможна, используйте альтернативные методы:

### Метод 1: Через веб-интерфейс сервера

Если у вас есть доступ к панели управления сервером (cPanel, Plesk, или другой):

1. Войдите в панель управления
2. Найдите "Файловый менеджер" или "File Manager"
3. Перейдите в `/var/www/ispravleno-website/backend/public/updates/`
4. Загрузите APK файл
5. Переименуйте файл

### Метод 2: Через облачное хранилище

1. **Загрузите APK в облако:**
   - Google Drive
   - Dropbox
   - Яндекс.Диск
   - Или любой другой файлообменник

2. **Получите прямую ссылку на скачивание**

3. **Попросите администратора сервера** выполнить:
   ```bash
   cd /var/www/ispravleno-website/backend/public/updates/
   wget "ВАША_ССЫЛКА_НА_APK" -O masterprofi-master.apk
   chmod 644 masterprofi-master.apk
   ```

### Метод 3: Через администратора сервера

Попросите администратора сервера:
1. Временно включить аутентификацию по паролю в SSH
2. Или добавить ваш публичный ключ в `/root/.ssh/authorized_keys`
3. Или загрузить APK файл напрямую на сервер

## Настройка FileZilla с SSH ключами

После настройки SSH ключей:

1. **Откройте FileZilla**
2. **Идите в:** Редактирование → Настройки → SFTP
3. **Добавьте ключ:**
   - Нажмите "Добавить ключ"
   - Выберите файл `~/.ssh/id_ed25519` (или `id_rsa`)
   - Введите парольную фразу (если вы её задавали)

4. **Подключитесь:**
   - Хост: `212.74.227.208`
   - Имя пользователя: `root`
   - Пароль: (оставьте пустым, будет использован ключ)
   - Порт: `22`
   - Протокол: SFTP

## Быстрая проверка

```powershell
# 1. Проверьте наличие ключей
ls ~/.ssh/

# 2. Покажите публичный ключ
cat ~/.ssh/id_ed25519.pub
# или
cat ~/.ssh/id_rsa.pub

# 3. Попробуйте подключиться
ssh root@212.74.227.208
```

## Если ничего не помогает

Обратитесь к администратору сервера с запросом:
1. Включить аутентификацию по паролю в SSH (временно)
2. Или добавить ваш публичный SSH ключ
3. Или загрузить APK файл вручную на сервер
