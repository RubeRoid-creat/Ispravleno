# Загрузка APK на сервер через FileZilla

## Пошаговая инструкция

### Шаг 1: Установка FileZilla

Если FileZilla не установлен, скачайте его:
- Сайт: https://filezilla-project.org/
- Выберите FileZilla Client для Windows

### Шаг 2: Подключение к серверу

1. **Откройте FileZilla**

2. **Введите данные для подключения:**
   - **Хост:** `212.74.227.208` ⚠️ **БЕЗ префикса `sftp://`!**
   - **Имя пользователя:** `root` (или ваш пользователь)
   - **Пароль:** (введите ваш пароль)
   - **Порт:** `22` (стандартный порт для SFTP)
   - **Протокол:** Выберите `SFTP - SSH File Transfer Protocol` из выпадающего списка

   ⚠️ **ВАЖНО:** 
   - В поле "Хост" вводите **ТОЛЬКО IP адрес**: `212.74.227.208`
   - **НЕ** вводите `sftp://212.74.227.208` или `sftp://` перед IP
   - FileZilla сам добавит протокол при выборе SFTP

3. **Нажмите "Быстрое подключение"** или нажмите Enter

   **Правильный формат:**
   ```
   Хост: 212.74.227.208
   Имя пользователя: root
   Пароль: [ваш пароль]
   Порт: 22
   Протокол: SFTP - SSH File Transfer Protocol
   ```
   
   **Неправильно:**
   ```
   Хост: sftp://212.74.227.208  ❌
   Хост: sftp://212.74.227.20   ❌ (неправильный IP)
   ```

### Шаг 3: Навигация к нужной директории

После подключения:

1. **В правой панели (удаленный сервер)** перейдите в директорию:
   ```
   /var/www/ispravleno-website/backend/public/updates/
   ```

2. **Способ 1 - через адресную строку:**
   - В правой панели введите путь в адресную строку:
   ```
   /var/www/ispravleno-website/backend/public/updates
   ```
   - Нажмите Enter

3. **Способ 2 - через навигацию:**
   - Дважды кликните на `/` (корневая директория)
   - Откройте `var`
   - Откройте `www`
   - Откройте `ispravleno-website`
   - Откройте `backend`
   - Откройте `public`
   - Откройте `updates`

### Шаг 4: Создание директории (если её нет)

Если директория `updates` не существует:

1. **Правой кнопкой мыши** в правой панели (на пустом месте)
2. Выберите **"Создать каталог"**
3. Введите имя: `updates`
4. Нажмите OK

### Шаг 5: Навигация к локальному APK файлу

В **левой панели (локальный компьютер)**:

1. Перейдите в директорию проекта:
   ```
   E:\Ispravleno\
   ```

2. Для **приложения мастера** перейдите в:
   ```
   E:\Ispravleno\app\build\outputs\apk\debug\
   ```
   Файл: `app-debug.apk`

3. Для **клиентского приложения** перейдите в:
   ```
   E:\Ispravleno\ClientApp\app\build\outputs\apk\debug\
   ```
   Файл: `app-debug.apk`

### Шаг 6: Загрузка APK файла

**Важно:** Файл должен быть переименован на сервере!

#### Для приложения мастера:

1. **Найдите файл** `app-debug.apk` в левой панели
2. **Перетащите** файл из левой панели в правую панель (в директорию `/var/www/ispravleno-website/backend/public/updates/`)
3. **Или:** Правой кнопкой на файле → **"Загрузить"**

4. **После загрузки переименуйте файл:**
   - Правой кнопкой на загруженном файле `app-debug.apk`
   - Выберите **"Переименовать"**
   - Введите новое имя: `masterprofi-master.apk`
   - Нажмите Enter

#### Для клиентского приложения:

1. **Найдите файл** `app-debug.apk` в левой панели
2. **Перетащите** файл из левой панели в правую панель
3. **После загрузки переименуйте файл** на: `masterprofi-client.apk`

### Шаг 7: Проверка загрузки

1. **Убедитесь, что файл загружен:**
   - В правой панели должен быть файл с правильным именем:
     - `masterprofi-master.apk` (для мастера)
     - `masterprofi-client.apk` (для клиента)

2. **Проверьте размер файла:**
   - Файл должен быть примерно 20-50 MB
   - Если размер 0 байт - загрузка не удалась

3. **Проверьте права доступа:**
   - Правой кнопкой на файле → **"Права доступа к файлу"**
   - Установите: `644` (rw-r--r--)
   - Нажмите OK

### Шаг 8: Проверка доступности

После загрузки проверьте, что APK доступен:

1. **Откройте в браузере:**
   - https://ispravleno.pro/apps/masterprofi-master.apk
   - https://ispravleno.pro/apps/masterprofi-client.apk

2. **Должно начаться скачивание файла**

### Шаг 9: Обновление версии (если нужно)

Если нужно обновить версию приложения:

1. **В FileZilla** перейдите в:
   ```
   /var/www/ispravleno-website/backend/
   ```

2. **Скачайте файл** `version-config.json` на локальный компьютер

3. **Откройте файл** в текстовом редакторе

4. **Обновите версию:**
   ```json
   {
     "android_master": {
       "current_version": "1.2.0",  // Увеличьте версию
       "min_required_version": "1.0.0",
       "force_update": false,
       "release_notes": "Что нового в этой версии...",
       "download_url": "https://ispravleno.pro/apps/masterprofi-master.apk",
       "supported_os_versions": ["8.0", "9.0", "10", "11", "12", "13"]
     }
   }
   ```

5. **Загрузите обновленный файл** обратно на сервер (замените старый)

6. **Перезапустите backend** через SSH:
   ```bash
   ssh root@212.74.227.208
   pm2 restart bestapp-backend
   ```

## Визуальная схема FileZilla

```
┌─────────────────────────────────────────────────────────┐
│  FileZilla                                               │
├──────────────────────┬──────────────────────────────────┤
│  Локальный сайт      │  Удаленный сайт                  │
│  (ваш компьютер)     │  (сервер)                        │
├──────────────────────┼──────────────────────────────────┤
│  E:\Ispravleno\      │  /var/www/ispravleno-website/    │
│  app\build\          │  backend\public\updates\          │
│  outputs\apk\        │                                  │
│  debug\              │  ← Перетащите сюда               │
│  app-debug.apk  ────→│  masterprofi-master.apk          │
│                      │                                  │
└──────────────────────┴──────────────────────────────────┘
```

## Важные замечания

⚠️ **Имена файлов должны быть точными:**
- `masterprofi-master.apk` (не `app-debug.apk`)
- `masterprofi-client.apk` (не `client-app-debug.apk`)

⚠️ **Права доступа:**
- Файл должен быть доступен для чтения: `644` (rw-r--r--)

⚠️ **Размер файла:**
- APK файлы обычно 20-50 MB
- Если файл 0 байт - загрузка не удалась, попробуйте снова

⚠️ **Безопасность:**
- Не сохраняйте пароль в FileZilla, если это общий компьютер
- Используйте SSH ключи для более безопасного подключения

## Устранение проблем

### Ошибка "Не удалось подключиться к серверу" / "Невозможно подключиться к серверу"

**Частые причины и решения:**

1. **Неправильный формат хоста:**
   - ❌ **Неправильно:** `sftp://212.74.227.208`
   - ✅ **Правильно:** `212.74.227.208` (только IP адрес)
   - Убедитесь, что в поле "Хост" нет префикса `sftp://`

2. **Неправильный IP адрес:**
   - ✅ **Правильный IP:** `212.74.227.208`
   - ❌ **Неправильный:** `212.74.227.20` (неполный IP)

3. **Неправильный протокол:**
   - Убедитесь, что выбран **SFTP - SSH File Transfer Protocol** (не FTP или FTPS)
   - Выберите протокол из выпадающего списка рядом с полем "Хост"

4. **Неправильный порт:**
   - Порт должен быть: `22` (стандартный для SFTP)
   - Оставьте поле пустым или введите `22`

5. **Проблемы с сетью:**
   - Проверьте интернет-соединение
   - Проверьте, что сервер доступен: `ping 212.74.227.208`
   - Возможно, нужен VPN или SSH туннель

6. **Проблемы с аутентификацией:**
   - Проверьте правильность имени пользователя: `root`
   - Проверьте правильность пароля
   - Возможно, нужно использовать SSH ключи вместо пароля

### Ошибка "Доступ запрещен"
- Проверьте правильность имени пользователя и пароля
- Убедитесь, что у пользователя есть права на запись в `/var/www/ispravleno-website/backend/public/updates/`

### Файл не скачивается с сервера
- Проверьте права доступа к файлу (должно быть 644)
- Проверьте, что файл загружен в правильную директорию
- Перезапустите backend: `pm2 restart bestapp-backend`

### Файл загружен, но приложение не видит обновление
- Проверьте версию в `version-config.json` - она должна быть больше текущей
- Проверьте URL в `download_url`
- Перезапустите backend
